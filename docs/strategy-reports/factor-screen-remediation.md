## 0. 执行摘要

**根因结论**

1. **负 alpha 的主体是"等权小盘 beta"，不是选股失败。** 同窗口（2026-04-30~06-22）按同一执行口径重算：全市场等权 20d 净收益 **−7.2%**，factor_screen 评分池等权 **−6.6%**，生产候选 **−5.3%**（CSI300 −0.2%）。候选相对自己的评分池有 **+1.3pp** 的正选股增量，相对全市场等权 **+1.9pp**；官方口径的 −8.7%/−8.3% 主要来自"始终在场、等权持有中小盘"在普跌窗口的全额 beta 暴露与路径复利放大。
2. **回测证据与现行代码是两代实现（可追溯性缺口，High）。** 窗口内 1011 行执行历史名单由 v1（`equity_strategies.multi_factor_selection`：winsorize+z-score、组权重 估值0.30/质量0.25/动量0.15/低波0.15/股息0.15）生成；现行 v2 是文件内 9 因子排名加权制。同快照重放 v2 与冻结名单重合率仅 **3%~26%**。官方 −8.7% 严格说是 **v1 的成绩单**，v2 从未被独立回测过（本次补算 v2 复刻为每笔口径 −5.4%，与 v1 名单 −5.3% 相当——负 alpha 与实现代际无关，进一步支持 beta 主导结论）。
3. **因子层面唯一持续负贡献是动量对（按当前打分方向）。** 窗口 20d IC：mom_12m −0.109、mom_3m −0.013；全样本（21 个可算快照日）mom_12m **−0.147（t=−3.15）**、mom_3m −0.086（t=−1.95）。估值（pe +0.18/pb +0.12）、低波（+0.21）、股息（+0.14）窗口内均为正 IC，综合分五分位 Q1→Q5 基本单调（窗口 Q5−Q1=+3.6pp）。**但直接剔除动量因子会恶化组合（模拟 −0.7pp）**，因为动量分是拉动组合流动性的唯一力量——因子手术在流动性治理之前做是反效果的。
4. **低流动性是"全链路无地板"叠加"评分池天然低换手"，不是评分刻意选小票。** 复现官方观察：信号日成交额 <2 亿的候选行 589/1011（58.3%）。评分池自身 fail 率 56~61%（全市场 51%），综合分与 log 成交额的秩相关近零（−0.10~+0.05）。对照组 uptrend_momentum 因入场过滤（`POLICY.entry_filters.min_daily_amount=2e8`）pass 率 98.2%——factor_screen 是策略家族中唯一完全绕过流动性口径的。fail 组窗口 20d 净收益 −7.6% vs pass 组 −2.1%（−5.5pp），流动性问题同时就是收益问题。

**推荐选项组合**（详见 §5、§6）

| 优先级 | 措施 | 依据 |
|---|---|---|
| P0 | **选项 a：宇宙预过滤**（近 20 日均额 ≥2e8，复用 `POLICY.entry_filters.min_daily_amount`），FORMULA_VERSION v2→v3 + 黄金样本 + 影响报告 | 模拟 pass 率 42%→100%，候选量不减（仍 30/日），窗口收益 +0.3pp 不恶化；治理的是可成交性而非窗口 alpha |
| P0 | **候选历史补记选股公式版本**（治理字段，`livermore_candidate_history.signal_evidence_json` 目前无 selection formula_version） | 本次审计暴露的断代问题不可复现、不可追溯 |
| P1 | **市场状态门控复审**：`factor_screen_active_states` 现含 OFF/OVERHEAT（永远在场），回测层面无敞口控制 | 负 alpha 主体是普跌窗口全额 beta |
| P1 | **选项 c 的上游化**：不调 `cycle_valuation_weight`（现 0.15，有效权重仅 9.75%），改为让 fusion 继承过滤后的干净候选 | fusion 253 行中仅 31 行（12%）受 factor_screen 影响 |

| 不推荐 | **选项 d 完全暂停**：改为"有条件保留 + 量化自动降级规则" | 候选在自身评分池内选股增量为正；股息/价值暴露对动量族有分散价值 |

### 1.3 复刻保真度（自检）

- **收益引擎**：与执行历史可比行对比，20d 净收益 408 行平均绝对差 **0.0005**（最大 0.0023），5d 857 行平均绝对差 0.0003——价格/复权/成本口径复刻成立。

### 1.4 与官方 −8.7% 的口径差异（重要）

官方数字来自 `portfolio_backtest` path 模式（逐日盯市、持仓期重叠复利、Sharpe −2.05 基于资金曲线）。本报告所有模拟为**每笔 20d 交易等权均值**口径：跨方案横向比较（Δ）有效，绝对值与 −8.7% 不可直接对照。另注意：执行历史表 20d 收益在物化时点冻结，1011 行中仅 408 行有值（`data_status='pending'` 480 行未回填）——本次复算绕开该表直接从行情重算，官方回测如直接消费该表存在样本截断风险（见 §7 发现 L1）。

## 4. 低流动性根因

### 4.1 复现与对照

- 信号日成交额口径：**pass 422 / fail 589（fail 58.3%）**，与官方观察一致；近 20 日均额口径 fail 58.0%——不是单日噪声；
- 对照 uptrend_momentum 同窗口 450 行：**pass 98.2%**。差异根源：动量族入场过滤强制 `daily_amount>=2e8`（`livermore_stock_candidates.py` 引用 `POLICY.entry_filters.min_daily_amount`），而 factor_screen 从快照直接选股，**全链路无任何流动性口径**。

### 4.2 评分驱动还是宇宙缺失？→ 宇宙缺失为主，子因子倾斜为辅

| 证据 | 数值 | 结论 |
|---|---|---|
| 评分池 fail 率（近20日均额<2e8） | 56~61%（10 期） | 池子本身过半不达标 |
| 全市场 fail 率（2026-05-27） | 51% | 池比市场略差 |
| 候选 fail 率 | 50~80%（均值≈58%） | ≈池水平，评分未系统性加重 |
| spearman(综合分, log成交额)（池内） | −0.10 ~ +0.05 | 综合分对流动性近中性 |

评分池构成（2026-05-27 快照）：5208 行中仅 **1485 行（29%）** 进入评分池，主要淘汰原因是 dividend_yield 缺失 35%、pe 缺失 27%（亏损/无分红票被 dropna+正值过滤剔除）。池内股票市值中位 82 亿**高于**全市场 62 亿，但近 20 日均额中位 1.60 亿**低于**全市场 1.93 亿——评分池天然向"低换手的大中盘价值/分红"倾斜，这是 58% fail 的结构性来源。

子因子层面确有分化（池内因子分与 log 均额秩相关，窗口均值）：

| 偏好低流动性（负） | 偏好高流动性（正） |
|---|---|
| volatility −0.378、pb −0.373、ps −0.171、pe −0.161、margin −0.059 | mom_12m +0.467、mom_3m +0.335、roe +0.116、div +0.095 |

低波+低估值把组合拉向低流动性，动量把它拉回来，净效应近零。**推论：任何"剔除动量/加重价值"的权重调整都会立即恶化流动性**（§5 选项 b 模拟证实）。

与 v2 基线候选重合率：A2 44%、A3 58%、B1 29%、B2 29%、B3 70%。

### 选项 a：宇宙预过滤（推荐，P0）

- **A2（绝对地板 2e8，预过滤后重排名）**：pass 率 42%→**100%**，候选量不减（仍 30/日，过滤后池约 600 只、top 10% 上限 30 生效），窗口收益 +0.28pp（不恶化）。核心收益不是窗口 alpha，而是**可成交性**：fail 组实盘还要叠加冲击成本，−7.6% 是下界而非期望。
- **A1 子集近似的 −2.0% 必须打折看待**：422 行只含 **43 只独立票**，且 TCL科技（+11.8%×34 行）、京东方A（+39.5%×16 行）、浪潮信息（+14.2%×21 行）三只贡献了大部分超额——有效样本极小，−2.0% 是运气成分很高的读数。稳妥的预期是 A2 的"+0.3pp、pass 100%"。
- **A3（池内 40 分位自适应地板）不推荐**：池成交额中位数仅 1.6 亿，40 分位阈值远低于 2e8，pass 率只到 73%，收益还更差；如果要分位口径，应对**全市场**分位而非池内分位。
- 实施口径建议：**近 20 日均额 ≥2e8**（比信号日单日额稳健，两口径窗口内 fail 率仅差 0.3pp），复用 `POLICY.entry_filters.min_daily_amount` 常量，不新造阈值。

### 选项 b：因子权重调整（押后，P2）

- **B1 教训**：机械剔除窗口负 IC 因子（动量对）使收益 **−0.69pp**、pass 率跌到 36%——动量分是组合内唯一的流动性正向力量，剔除后价值/低波/股息把组合推向更小更不流动的票，规模通道的损失盖过因子方向的收益。
- B2（剔估值+股息，保质量+动量+低波）窗口 +0.71pp 且 pass 率 71%，方向上有信息（再次指向流动性通道），但 10 个快照日不构成调权证据，且与 B1 一样是**在样本内挑权重**。
- **正确顺序**：先做选项 a（流动性中性化），再积累 ≥50 个快照日，做"流动性分层内的因子 IC"验证 mom_12m 的负号是否残存，届时才谈剔除/反向。

### 选项 c：降低 factor_screen 在 hybrid_fusion 中的权重（二级，随 a 上游治理）

现状（`config/hybrid_fusion_strategy.yaml` = 代码默认）：

- `cycle_valuation_weight=0.15`、`fusion_cycle_weight=0.65` → factor_rank 在最终 fusion 分中的**有效权重仅 9.75%**（macro 缺席的 legacy 路径 0.65×0.30=19.5%）；
- 依赖度实测：253 行 hybrid_fusion 候选中 `factor_rank_available=true` 仅 **31 行（12%）**，且这 31 行全部是"仅 factor_screen 单一来源"进入 fusion 候选池的（factor_screen 还承担**供票**角色，不只是打分项）；
- `factor_rank_available=false` 时代码已做权重重归一（无 0 分惩罚），停供不会破坏 fusion 打分。

**结论**：调权重是弱药——9.75% 的权重再砍也改变不了什么，反而增加一次配置变更审计。正确做法是选项 a 在上游把候选洗干净，fusion 自动继承；若仍要降权，`cycle_valuation_weight 0.15→0.10`（余额归入 industry）是可接受幅度，需同步改 yaml 与 `validate_thresholds` 的权重和=1 校验样本。

### 选项 d：暂停候选输出/观察名单化（不推荐全停）

- 反对全停的证据：候选在自身评分池内选股增量为正（+1.3pp）、综合分五分位单调、全样本综合 IC 弱正；其价值/股息暴露与动量族互补；
- 支持降级的证据：绝对收益差、无门控、无流动性地板、v2 无回测记录；
- **建议形态**："有条件保留"——实施 a 后保留候选输出，同时挂**自动降级规则**：滚动 3 个月每笔 20d 净收益相对评分池等权增量 < 0，或流动性 pass 率 < 95%，则页面标注降级为观察名单（不进入 fusion 供票）。降级开关走 `strategy_policy`/monitoring 配置，不是删代码。
- 若管理层仍要立即停供：最小改动是把 `factor_screen_active_states` 置空集（策略仍计算、门控拦截输出），影响面见 §6.3。

## 6. 推荐方案与实施要求

### 6.1 推荐组合

**P0（一个变更包）：选项 a（≥2e8 宇宙预过滤）+ 候选历史版本字段补记 + 监控降级规则（选项 d 的软形态）。**

### 6.2 P0 实施要求（对齐仓库变更纪律）

1. **代码落点**：`_filter_factor_screen_universe`（`backend/app/core_finance/factor_screen_candidates.py`）新增流动性条件；成交额数据需由服务装载层 `_load_factor_screen_rows`（`market_data_livermore_service.py`）从 `choice_stock_daily_observation` 只读关联近 20 日均额传入（API/service 保持 DuckDB 只读，符合架构边界）；
2. **FORMULA_VERSION**：`rv_factor_screen_candidates_v2 → v3`，payload `coverage_note`/`filtered_out_count` 说明流动性过滤口径与剔除数；
3. **黄金样本**：固定一个快照日 fixture（建议 2026-05-27，池 1485 只）锁定：过滤前后池规模、前 30 名单、每只候选近 20 日均额 ≥2e8 断言；
4. **影响报告**：候选构成变化（与 v2 重合率约 44%）、评分池规模 1485→~640、下游三个消费面（§6.3）逐一确认；
5. **阈值来源**：引用 `POLICY.entry_filters.min_daily_amount`，禁止在 factor_screen 内新写 2e8 字面量；
6. **候选历史治理字段**：`livermore_candidate_history` 物化任务在 `signal_evidence_json` 中补记 `selection_formula_version`（tasks 层写入，符合写路径边界）；

### 6.4 需要更长窗口验证的事项（P2 清单）

1. **动量因子方向**：mom_12m 全样本 IC −0.147（t=−3.15）是本审计最接近"可行动"的因子发现，但需 ≥50 个快照日 + 流动性分层中性化后复验（当前动量 IC 与流动性暴露纠缠）；
