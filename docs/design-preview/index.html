全局统一美观度 · 前后对比样张

每张样张右上角有 「现状 | 目标态」开关。同一个页面结构，只换设计令牌（token）——布局、间距、字号两态完全一致， 差异只在颜色、圆角、阴影、字体声部与装饰元素。这就是整份方案的核心主张：不是重排页面，而是让全站说同一种视觉语言。

① 深色终端页 原型：组合 / 市场首页 · 亮蓝系 → dh-api 去饱和终端

深色页的变化刻意克制：亮天蓝 #7dd3fc 收敛为去饱和灰蓝 #72a7dc，荧光绿收敛为沉绿； 发光阴影与渐变装饰带退出，层级靠三层面板底色递进 + 发丝线；刊头衬线退出；KPI 数字换等宽终端声部。 深色页本来就接近目标，统一的是「四个页面四套色」的分裂。

② IB 浅色页 原型：报表 / 工作台页 · 大圆角杂色蓝 → 纸感锐角藏青

浅色页的变化最直观：20px 大圆角 + 弥散阴影收敛为 2px 锐角 + 一档 1px 阴影；两种蓝混用收敛为唯一藏青 #14366b；装饰渐变条删除，结构分区交给发丝线；数字全部等宽 tabular；装饰彩点改为只承载语义的绿 / 黄 / 红状态点。

④ 评审看点

  • 切回「现状」时哪里让你觉得乱？那些点就是本次要消灭的分裂（杂色、圆角、装饰）。
  • 「目标态」是否够安静？目标是「冷静、可审计」：第一眼看结论与数字，第二眼看状态，没有第三层噪音。
  • 深色页的克制度能否接受？accent 从亮蓝换灰蓝是唯一需要你适应的色相变化（决策点 D4）。
  • 浅色页的锐角是否太硬？2px 是机构纸感的关键；如果你觉得太硬，这是拍板前最好的提意见时机。
  • 两张样张均为演示数据；与真实页面的差异仅在内容量，视觉规则 1:1 对应。
