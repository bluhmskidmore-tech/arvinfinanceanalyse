# MOSS Ontology

This directory stores the machine-readable projection of existing MOSS semantic
authority.

Authority still lives upstream in:

- `docs/metric_dictionary.md`
- `docs/page_contracts.md`
- `docs/calc_rules.md`
- `docs/golden_sample_catalog.md`

`moss_ontology.v1.json` is only a read-only index over those documents. It must
not introduce new metric definitions, formulas, or formal-use approval.
