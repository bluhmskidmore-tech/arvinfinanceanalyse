# 净价估值与月末手工补息口径备忘

记录日期：2026-07-22

适用范围：`/pnl-attribution`、债券组合风险及月末损益归因

状态：业务口径备忘，尚未替代正式指标合同或会计制度

## 已确认的业务事实

1. 当前系统只能进行净价/竞价估值，无法取得足以自动拆分 Carry 的全量输入。
2. 贴现同业存单的 `coupon_rate` 缺失是系统及产品口径导致，不应视为普通附息债的数据缺失。
3. 月末利息按“全价与竞价净价的差额”人工计算并补记入账。
4. 4 笔已过合同到期日的头寸属于逾期资产，仍需计入组合市值和损益，不应清零、删除或修改为未来到期日。

## 正确的计算边界

### 净价估值系统负责

- 按净价计算持仓市值；
- 计算净价变动产生的估值损益；
- 在风险参数可靠时计算久期、DV01 和 KRD；
- 保留估值日期、价格来源和竞价估值口径。

### 月末手工凭证负责

- 利息收入；
- 贴现摊增；
- 全价与竞价净价之间的月末调整；
- 实际入账金额及其凭证、编制和复核证据。

### PnL 桥接

```text
正式总 PnL
= 净价估值损益
+ 实际手工补记利息
+ 交易/实现损益
+ 其他调整
+ 残差
```

不得使用以下替代逻辑：

```text
coupon_rate = 0
=> Carry = 0
```

`coupon_rate = 0` 只能表示没有期间现金票息，不能证明经济 Carry 或会计利息为零。

## 系统取不到手工补息时的处理

### 可取得月末手工凭证或受控文件

将实际补记金额作为正式利息来源。最少应保留：

- 报告日；
- 组合或成本中心；
- 券码（能够提供时）；
- 补记利息金额；
- 币种；
- 凭证号；
- 入账日期；
- 编制人与复核人。

如果只能取得组合或成本中心合计，可以闭合组合总 PnL，但不得将金额无依据地分摊至具体债券或期限桶。页面应标记为“组合层手工利息调整”。

### 完全取不到补息金额

页面只能报告：

- 净价估值损益：可计算；
- Carry/利息：待手工补录；
- 与正式总 PnL 的差额：未分配调整项。

不得自动把未解释差额全部命名为 Carry。

## 月末余额与当月发生额

若“全价－竞价净价”是月末累计应计余额，不能每月将期末余额全额重复计入 PnL。优先使用实际凭证发生额。

若只有应计余额，原则上需要：

```text
当月利息调整
= 月末应计余额
- 上月末应计余额
+ 本月已支付或冲回金额
```

实际处理仍应服从月末是否冲回上月凭证的会计流程。

- 不清零、不删除、不修改为未来到期日；

- 利息只认实际手工补记，不根据原合同到期日继续自动计提；

- 估值覆盖率：有有效竞价净价的持仓覆盖；

- 逾期资产市值：独立列示，不与无到期日资产混同。
