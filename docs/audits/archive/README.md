# 过程文档存档（docs/audits/archive）

本目录存放 `docs/audits/` 下已完成、不再需要在日常开发中阅读的一次性审计/过程文档。这些文档记录的是当时的调查结论、检查清单或验收快照，属于历史留痕，**不代表当前系统状态或当前权威规则**。

- 归档范围：文档名带 `YYYY-MM-DD-` 日期前缀、日期早于 2026-07-01、且未被仓库内其他文档、脚本或测试引用的文档。
- 未归档说明：`docs/audits/` 下日期早于 2026-07-01 但仍被其他文档、脚本或测试引用的文档，为避免破坏引用链和测试契约，暂未移动，仍保留在 `docs/audits/` 根目录。
- 如需追溯某次历史审计的完整结论，直接在本目录按日期查找即可；如需了解当前有效的治理/设计结论，请查阅仓库根目录的权威文档（如 `DESIGN.md`、`AGENTS.md`）而非本目录。
