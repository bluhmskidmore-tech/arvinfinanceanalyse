# WRITING.md — 管理层决策册文字规范

适用对象：所有基于本模板生成的 1280×720 管理层决策册（宏观策略册、经营分析册、监管专册等）。
修订入口：文字表述问题改这里；版式问题改 `template.css`；页面容量问题改 `components.html` 头部注释。

以下每条规则都对应旧版报告（V20260811.8 及金融市场经营分析 V20260817.x 系列）的实际缺陷，禁止回退。

## 1. 标题

- 页标题（`h1`）**不超过 18 个汉字，只表达一个结论**。是判断句，不是主题词。
  - 反例（旧版 P03，27 字 5 个论点）：提请审议：存单定价、融资稳定性、7Y迁移、监管专项与RAROC口径五项动作
  - 正例：提请审议三项风险复核动作
- 放不进标题的论点写进 `deck`（一行以内）或拆页，**不许靠加长标题解决**。
- `deck` 只承担两类内容：口径/日期说明，或标题的量化补充。不放第二个结论。

## 2. 免责与口径声明

- 每页免责声明**只出现一次，固定在页脚 `.foot .disclaimer`**。
- 正文、卡片、括号里禁止重复"（建议 · 待审批）""（未经审计）""不构成交易指令"等字样。
  同页需要多处标注状态时，用状态签（`tag-status`：正常/关注/警示）或在页脚一句话覆盖全页。
  - 反例（旧版 P03 同页出现 5 次"建议 · 待审批"）。
- 全册口径边界集中写在专门的"数据来源与口径"页，正文页只引用页码。

## 3. 数字

- **一句话最多出现 2 个数字**。第 3 个数字出现时，改用表格、KPI 格或图表。
  - 反例（旧版 P02）：7月20–24日券商和基金分别净买入536亿元、449亿元，月底基金继续净买入332亿元。
  - 正例：券商和基金 7 月下旬持续净买入超长债（明细见右表）。
- 禁止三连括号补充。"（含存单补录）（占8.01%）（P37）"式写法必须改写：口径进页脚，出处用 `src` 行，比例进正文主句。
- 千分位分隔；单位紧跟数字；环比/同比写"环比 +26.9 亿元"，不写"MoM +26.9"。
- 页码引用统一格式"证据 → P04–P08"，用中文引导词。

## 4. 术语

- 内部代号与英文缩写**首次出现必须给中文说明**：zqtz（债券投资控制口径）、KRD（关键期限久期）、DV01（基点价值）、analytical（经营分析口径）。
- 全册维护一个术语表页；正文再次出现时可直接用代号。
- 禁止把系统字段名（quality=warning 等）原样写进管理层正文，改写为"数据质量提示见页脚"。

## 5. 中英文

- 正文、卡片标题、表头、标签**一律中文**。
- 英文 mono 仅允许出现在：页眉 `.chrome`、`sec-label .en` 小注、数字本身。
- 禁止用英文大写标签承载业务含义（反例：FORMAL FI GROSS P&L、CANDIDATE、OBSIDIAN DECISION RECORD）。读者不应需要翻译才能理解页面结构。

## 6. 每页容量（超限拆页，不许缩字号）

| 页型 | 上限 |
| --- | --- |
| 封面 | 核心结论 1 条 + KPI 3 个 |
| 摘要 | 结论 4 条 + 立场表 6 行 |
| 决策 | 决策卡 3 张 + 仪表盘 4 格 |
| 图表 | 主图 1 幅 + 注释 4 条 |
| 表格 | 单表 14 行 |
| 监管 | 三栏各 4 条 |

- 每页正文最多一条结论条（`houseview`），承载本页唯一核心判断。
- 阅读路径、页码说明等导航信息只出现在目录页，不逐页重复。

## 7. 事实、判断与建议

- 监管与决策类页面必须区分三层：事实（有来源）、判断（本行视角）、建议（待审批）。用 `layout-reg` 三栏或分区标题实现，禁止混写在同一段。
- 建议类内容一律标注责任条线与时限（写入卡片 `meta` 行），没有责任人的建议不上页。

## 8. 出版纪律（投行级）

对标卖方研究与董事会材料的出版标准，逐条硬性执行：

- **Exhibit 编号**：每个图和表都套 `exhibit` 结构，编号"图表 页码-序号"（如 图表 9-1），
  头部左标题右单位。正文与其他页引用编号，禁止写"下图""上表"。
- **资料来源行**：每个 exhibit 底部必有 `exhibit-src`，统一格式
  "资料来源：〈来源，多个用逗号分隔〉；数据截至 YYYY-MM-DD。"来源写到系统/机构级，不写"内部数据"。
- **脚注**：口径限制、剔除项、一次性因素写编号脚注（`footnotes` + `sup`），不塞正文括号。
  每页脚注 ≤3 条，超出说明口径本身该上"数据来源与口径"页。
- **数字排版**：全册 tabular-nums 等宽数字（模板已内建）；表格数字右对齐；负数统一用
  "−"（U+2212）；红色只表达"对本行不利"，不自动等于负号（成本下降是负数但有利，用绿色）。
- **图表去装饰**：只保留横向网格线；数据点直接标值，不用图例；序列 ≤3 条（超过拆图）；
  最新值/关键值用实心点与主色高亮（`pt-last`/`lbl-last`）；利差、事件用虚线注释（`annot-line`）。
- **机密等级**：每页页眉中段固定"内部资料 · 机密"（`chrome .conf`），对外版本改为对应等级，
  禁止只在封面标注。
- **Title-only test**：全册标题连读应构成完整结论链（宏观→曲线→容量→回报→风险→行动）。
  成稿后把所有 `h1` 抽出来通读一遍，读不通就改标题，不改正文。

## 9. AI 文风净化（AI 生成材料强制执行，成稿必须逐条自查）

本节针对 AI 生成分析文字的典型缺陷：生硬机械、设问反问、空转填充。
以后此类材料常规由 AI 产出，本节与第 1–8 节同等强制。

**句式禁令**

- **禁止反问与设问**。"为什么 DV01 下降？主要因为…"改为"DV01 下降主要来自…"。
  全册正文问号数量必须为 0（引用监管文件、市场观点原文除外）。
- **禁止空转填充词**：值得注意的是 / 需要指出的是 / 不难发现 / 可以看到 / 显而易见 /
  进一步来看 / 与此同时 / 事实上 / 换言之。删掉后句子仍成立的，一律删。
- **禁止空洞总起与总结**："本页主要分析…""综上所述""总体来看""整体而言"。
  每段第一句就是结论本身，最后一句不复述。
- **禁止机械排比**：连续三段（或三张卡片）用同构句式开头即判定机械。
  "一是/二是/三是"只允许用于并列动作清单，且每条必须是完整判断句，不是名词短语。
- **禁止凑排面的四字对仗**："稳中有进、质效齐升"类空话，除非引用原文并注明出处。

**表达规范**

- 每句要有信息增量：主语 + 判断 + 依据。删了不损失信息的句子直接删。
- 因果直给："A 导致 B" / "B 主要来自 A"，不写"之所以…是因为…"。
- 转折克制：一段最多一个"但"。"虽然 A，但是 B"改为先说 B，A 作让步状语或删除。
- 不拟人、不渲染：数据不"表现亮眼"，市场不"情绪回暖"，风险不"值得警惕"
  （市场观点页转述他人观点时除外，且要标注机构来源）。
- 判断有归属：分清"本行判断 / 市场观点 / 监管表述"，禁止无主语的"预计""认为""有望"。

**成稿自查（三步，缺一不可）**

1. 全文搜索"？"，正文命中即改写为陈述句。
2. 按上面填充词清单逐词搜索，命中即删改。
3. 朗读测试：任选三页读出声，应像部门负责人向行领导当面汇报，不像课件讲解或
   公众号文章。读着"顺但没内容"的句子，删。
