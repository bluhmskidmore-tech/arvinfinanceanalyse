# 首页通胀来源与历史展示验收

## 结果与原因

2026 年 9 月 16 日，首页中国通胀已更新至八月，CPI 同比为 0.8%，PPI 同比为 3.8%；七月前值分别为 0.5% 和 3.5%，两项较前值均增加 0.3 个百分点。正式读取接口、原始公告、入库行和浏览器显示已逐项核对。

原刷新链路只为 CPI/PPI 调用 Tushare，其实际观测止于七月。新链路从国家统计局发布列表发现公告，在既有 raw archive、catalog、source manifest 与标准化 ETL 体系内落地，首页按实际观测期间选择来源，同期优先使用官方数据。默认采集最近两个完整月份，便于从同一来源读取前值；也支持精确指定一个月份。没有用其他月份或其他来源的数据拼补前值。

首页已有历史数据组件被一条 CSS selector 隐藏，此次恢复其折叠入口，并将误用的“更多日历”改为“过往数据与变动”。来源前缀曾由正文和 CSS 同时生成，删除重复生成后统一显示“来源：国家统计局”。状态和必要业务警示保留，内部供应商选择诊断继续留在 API 与血缘证据中。

标准表使用月初日期表示观察期间，单位为 `pct`。页面显示 `2026-08` 与 `2026-07`，变化单位为百分点。接口 `release_date` 保持空值，原文保留官方发布时间，采集时间没有冒充发布时间。

## 后续刷新入口

本机默认出口访问国家统计局会出现 TLS 连接提前关闭。正式入口现在支持校验并指定本机 IPv4 地址，HTTPAdapter 只影响该采集 Session，保留证书验证并拒绝重定向。独立只读实抓已验证，不需要修改全局 socket 或使用临时包装脚本。

本次批次已经完成。后续只刷新 CPI/PPI 时使用以下入口，`YYYY-MM` 替换为实际需求月份；省略月份会取最近两个完整月份。本机此次验证的地址为 `172.16.115.248`，其他主机须使用自身有效地址。

```text
.venv\Scripts\python.exe -m backend.app.tasks.nbs_inflation_release_ingest --source-ip 172.16.115.248 --reference-month YYYY-MM
```

既有整套首页宏观刷新入口也可传 `--nbs-inflation-source-ip`，该参数只控制 CPI/PPI 采集。长期 worker 尚未重载新任务代码；带新参数入队前须按既有运维流程重启 worker。未传参数的同步和入队命令保持原有零参数调用，兼容现有 worker。同步 CLI 在新进程中加载新代码。本次没有新开定时刷新。
