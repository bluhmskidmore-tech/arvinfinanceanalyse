# 市场总览 PRD：解释资金与利率变化，并查看组合情景影响

版本：1.1；编写日期：2026-09-08；状态：已实施页面及证据契约，真实来源缺口仍按文末记录保留。页面为 `/market-overview`，对应 `PAGE-MARKET-HOME-001`。本文属于 supporting 产品需求文档；需求正文描述目标行为，实际交付范围见“实施记录”，不替代现行指标字典、金融计算口径或页面契约。

本次改造让用户在市场总览中读懂资金价格和国债曲线的变化，核对判断依据，并查看明确假设下的组合敏感性。一期集中完成资金条件、利率定价和固定利率冲击情景；信用、增长通胀和外部扰动保留观察入口，后续再补充完整分析。

本文确定产品范围、默认交互、信息取舍和验收要求。尚无充分证据确定的业务口径标为 `PENDING`，并同时规定缺口存在时的页面行为。研发不得自行用固定阈值、代理指标或旧日期消除这些缺口。

## 一、当前问题与改造目标

用户的主要问题是：页面有很多表格、图表和后端输出，但难以辨认哪些信息重要、结论依据是什么、变化如何影响资产。此前已经压缩重复内容、统一行情表并将部分核验信息折叠；这些工作改善了阅读，仍未完成业务解释。

2026-09-08 的代码与只读接口核对确认了以下问题。这里记录系统返回及实现行为，不将本地行情认定为当日已核验的市场事实。

| 核实事项 | 当前情况 | 相关证据 |
| --- | --- | --- |
| 判断依据 | 流动性标签依赖固定绝对利率阈值 | [流动性规则](../backend/app/services/macro_toolkit_analysis_service.py) |
| 综合判断 | 对少数方向标签计票，未纳入页面全部宏观证据 | [结论组装](../backend/app/services/macro_toolkit_route_support.py) |
| 状态一致性 | 综合判断被阻断时，局部方向卡仍可能保留标签 | [快照组装](../backend/app/services/market_overview_service.py) |
| 指标名称 | `3M NCD` 的实际输入为 `NCD.SHIBOR.3M` 代理 | [指标映射](../backend/app/services/macro_toolkit_route_support.py) |

改造后，用户应能在本页回答三个问题：所示观察期内发生了什么变化；判断引用了哪些数据、有什么限制；在指定利率冲击下，组合会产生多大的敏感性影响。页面不生成买卖指令，不把经济机制解释写成已验证因果，也不将情景结果表述为收益预测。

## 二、用户、范围与完成标准

主要用户是银行债券投资及研究人员，日常用于查看市场、核对曲线变化和了解组合利率暴露。管理人员可以直接阅读摘要，再按需展开证据。数据维护人员通过既有核验入口处理来源和刷新问题，操作信息不与市场判断混排。

| 内容 | 一期安排 | 后续安排 |
| --- | --- | --- |
| 资金条件 | DR007、有效政策基准、SHIBOR 参考及变化解释 | 真实存单、资金分层、历史分位 |
| 利率定价 | 国债关键期限变化、期限利差及变化解释 | 国开与国债比较、曲线历史分位 |
| 关联效应 | 条件性机制解释、同一观察期的事实核对 | 经样本和稳定性检验的统计关联 |
| 持仓影响 | 监管口径下平行上行 10 bp 的组合情景 | 下行与非平行情景、账户和持仓拆分 |
| 信用、宏观、外部 | 保留数据日期、背景证据与专题入口 | 分别建立完整判断依据 |

一期不新增统一评分引擎、不重建全站组件体系、不调整数据库基础架构，也不重做刷新调度。采集恢复继续使用系统既有流程；若共享服务中的名称或门控问题是直接根因，可作最小修复并验证其其他调用方。

完成标准分为功能和使用效果。功能上，两块市场分析、同日组合情景的正常路径以及缺失、失败路径均须验收，不能仅交付版式或跳转入口就称一期完成。使用效果以小范围走查为准：至少三名目标用户能在一分钟内指出观察期、主要利率变化和一条限制，并在两次操作内打开对应依据。这是拟定验收目标，目前没有实测结果；不为此新增全站埋点工程。

## 三、用户在页面上的阅读与操作

进入页面时，用户先看到“资金与国债观察”摘要，以及分别标明的资金观察日和曲线观察日。资金观察日取本块实际采用的DR007观测日期，曲线观察日取本块实际采用的国债曲线日期。摘要最多两句，分别概括资金和曲线事实；一期不再把信用、股票和商品的方向标签等票相加，形成泛化的“中性偏积极”。证据不足时直接说明哪部分暂不判断。

摘要下面是“资金条件”和“利率定价”两个常驻分析区。宽屏并排，窄屏依次排列。每区先给一句带对象和期间的结论，再展示关键数字和图表，随后用简短文字解释含义及限制。“查看依据”打开该结论的原始观测、比较对象、日期和来源，而非另一个重复摘要。

用户点击“查看组合情景”后，页面按需加载固定利率冲击结果。该情景以利率定价区的曲线观察日为日期参照，情景区同时显示曲线观察日、实际风险数据日、适用组合范围和冲击条件。需要进一步检查时，进入 `/risk-tensor?report_date=所选风险日期`，沿用目标页已有的日期参数。

宏观背景和事件放在主分析区之后。宏观数据按各自月份展示；新闻须区分事件时间与接收时间，现有事件数量不得改称“市场冲击强度”。专题图表、全部行情、记录核验继续按需展开，保留搜索、分页、直接锚点和原始精度。

首页默认展示资金利率走势、两期国债曲线和关键利率近20期对照，图表位于明细表及长解释之前。资金和曲线卡片的受限原因、代理身份、政策待核验状态保持可见，明细和完整解释按需展开。关键利率对照沿用现有序列，不将走势并列解释为因果；同日国债与国开期限结构保留在专题中。十二项专题图表入口全部保留，其中关键利率对照和跨资产变动引用首页实际原图，不重复绘制。

跨资产变动保留在首页下方，每项直接显示自身比较起止日期；不同期间的结果不能称为今日涨跌排行或市场共振。宏观指标明细和事件密度默认折叠，展开后保留各自日期与使用限制。

刷新失败或权限受限的原因应在受影响区域直接可见。技术异常栈、主机地址和版本散列留在核验信息中；用户看到的是影响范围及可采取的既有操作。

## 四、资金条件：说明资金价格处在什么位置

### 输入与展示

DR007 是一期主观察指标。政策基准必须是对 DR007 观察日有效、且有来源和生效记录的政策利率。现有“7天逆回购中标利率”是操作日观测，不能未经核验就当作在所有后续日期持续有效的政策利率。

| 展示项 | 一期规则 |
| --- | --- |
| DR007 | 原值、单位、观察日、比较日和变化 |
| 政策基准 | 利率值、生效日期、有效性状态 |
| 相对政策基准偏离 | 后端返回的差值，单位 bp |
| SHIBOR 3M | 标明“期限报价参考”，保留自身日期 |
| 资金走势图 | DR007 与可验证政策基准；SHIBOR 可切换查看 |
| 判断依据 | 当前观测、比较基准、适用限制与来源 |

实际绑定为 `NCD.SHIBOR.3M` 时，页面名称必须为“SHIBOR 3M”，不能显示成真实存单发行或二级市场收益率。真实存单不列为一期必要输入，缺少它不阻断 DR007 的独立事实展示，也不允许用 SHIBOR 补出存单利差。

趋势图默认展示近 20 个市场交易日的可用观测，真实缺口留空。如果来源只支持最近 20 期而无法证明交易日完整性，明确标为“近20期”，不展示连续天数。政策基准只有在生效区间得到证明后才能画为阶梯线；原始操作利率仍只画操作日观测。

### 结论与计算边界

一期先使用可核对的描述，例如“DR007 低于有效政策基准，较比较日回落”，并附具体差值和日期。不能仅因 DR007 低于某个绝对数值，就把整个资金环境称为“宽松”；偏离为负也不自动等同于货币政策宽松。

政策偏离由后端计算。两项利率以百分数数值返回时，偏离的基点数等于二者之差乘以 100；单位不明时不计算。该结果属于本页分析展示，不因使用正式输入就自动成为新增正式指标。

DR007 的跨期变化必须说明比较日。若前一交易日缺失，可以保留最近一次有效观测作为显式的“较某日变化”，但不得称为“日变化”，也不得参与要求连续交易日的趋势判断。政策基准有效性无法证明时，只展示 DR007 及其自身变化，偏离显示“政策基准待核验”。

解释文字需要限定对象：DR007 回落说明所示存款类机构7天回购资金价格回落；本行融资成本是否同步变化，需要实际融资数据。SHIBOR 期限报价上行而 DR007 下行时，应并列说明分歧，不能平均后给出一个“偏松”标签。

“偏松、偏紧”的分档、持续期和历史分位不在一期默认规则中。相关窗口和阈值未完成业务确认前，采用数值事实及明确条件表达，避免把待定参数埋入代码。

## 五、利率定价：说明哪些期限发生变化

### 曲线与比较方式

一期以正式国债收益率曲线为主，优先展示 2、5、10 年节点。1 年、30 年等节点在来源和比较日期有效时补充；国开数据缺失时不绘制替代曲线，不以国债代替国开。

默认比较最新可核验国债曲线日与其前一市场交易日。两条曲线必须属于相同曲线族和估值口径。各节点显示当期收益率、基期收益率及基点变化，图上叠加两期曲线，下面使用同一套数据展示分期限变化。

| 展示项 | 一期规则 |
| --- | --- |
| 关键期限收益率 | 百分比显示，保留曲线日 |
| 分期限变化 | 基点显示，正负号及比较日明确 |
| 10年减2年期限利差 | 当期值、基期值、利差变化分别展示 |
| 10年减5年期限利差 | 同上；独立校验必要节点 |
| 曲线解释 | 点明变动较大的期限和斜率变化 |
| 证据明细 | 曲线族、期限、两期原值、单位和来源 |

计算必须在后端完成。收益率变化与期限利差变化都用 bp 表示，不能将百分比、百分点和收益率相对涨跌幅混用。期限利差每一期的两个节点都必须同日；利差变化还必须在相同的起止日之间比较。

现有 `derived_spreads` 属于分析展示读面，复用前仍须检查两条腿的日期、单位和可用性，不能因为字段非空就跳过校验。任一必要节点缺失、陈旧或采用不允许的回退时，该项派生判断不可用；其他独立有效节点可以保留。

### 结论与反向证据

一期用完整句子描述形态，例如“2年收益率降幅大于10年，10年与2年的期限利差扩大”。若变化方向不一致，则点明“短端上行、长端下行”及各自幅度。页面不强求把每种曲线形态压缩成一个交易术语。

没有历史分位，不能仅凭绝对收益率判断“便宜”或“配置价值高”；没有供需和事件证据，不能把曲线上行解释成“机构抛售”。资金区与曲线区走势不同步时，摘要应保留差异，不强行写成统一方向。

单个节点或部分节点有效时，标题写清覆盖范围。2、5、10年任一必要节点缺少跨期比较数据时，不形成覆盖三段期限的整体曲线判断；已具备完整两期数据的期限利差可独立解释。

## 六、关联效应：解释条件，不制造原因

一期在两块分析区下各提供一段“如何理解”。解释包含已观察的变化、可能影响的对象、成立条件以及尚未验证的部分。观察事实由本期数据支持；机制文字是条件性说明，不能仅因两项数据同时变化就宣称存在因果。

资金区可说明：若市场资金价格回落持续传导至实际融资成本，持券融资负担可能下降；当前页面没有本行融资合同和成本数据，因此不输出本行成本下降金额。利率区可说明：固定利率债的价格对收益率变化存在敏感性，具体组合影响应到明确冲击假设下查看，不能直接将今日单个期限变化乘以整个组合 DV01。

历史相关性和领先滞后不进入一期主结论。现有联动接口可作后续专题依据，但引入前必须排除同义序列与自身相关，核对样本、频率、日期对齐、窗口和稳定性。相关系数不代表因果强度，规则置信等级也不代表预测胜率。

与资金、曲线判断有关的月度宏观背景可以附在证据后，显示实际统计期和可得发布日期。缺少发布日期时不能用于“当时市场已知信息”的回放解释。月度背景与日行情不同频本身不构成异常，不能把同月标签当成同日信息。

## 七、持仓影响：复用固定利率冲击情景

### 一期能力与入口

优先复用 `GET /api/risk/scenario-stress?report_date=YYYY-MM-DD`，只读取 `scenario_key=parallel_rate_up_10bp` 的结果。现有场景为“利率平行上行10 bp”，使用 `regulatory_dv01`，返回金额单位为 `yuan`，并标记 `basis=scenario` 和 `human_review_required=true`。

一期标题为“利率上行10个基点时的组合敏感性”。正文说明这是已物化监管口径 DV01 下的线性冲击估算，保留“情景估算、需复核”标识，不展示为实际损益、未来利润、完整债券重估或投资建议。监管口径 DV01 绑定既有 `MTR-RSK-001R`，不与组合 DV01、利率风险 DV01 相互替代。

| 页面必须显示 | 来源或约束 |
| --- | --- |
| 冲击条件 | 固定平行上行10 bp |
| 风险口径 | 监管口径 DV01 |
| 影响金额 | 指定情景行的后端返回值 |
| 金额单位 | 保留元口径；可明确换算为万元展示 |
| 曲线观察日 | 利率定价区实际采用的曲线日期 |
| 风险数据日及范围 | 已核验的实际风险来源信息 |
| 使用限制 | 情景估算、需复核及来源警告 |

不读取 `summary.worst_estimated_impact` 作为最大损失，因为现有摘要可能混合价格影响与流动性缺口变化。没有下行、非平行或账户拆分结果时，不在前端取反、按比例拆分或使用总 DV01 替代期限风险。

### 日期、权限与缺失状态

首次打开情景区，优先检查是否存在与曲线观察日一致的有效风险结果；不能改用较新的DR007日期。曲线日期缺失时不推断默认情景日，可保留风险详情入口。同日结果不可用时，显示“缺少同日风险数据”，可以提供经现有风险日期入口确认的最近可用日期，由用户显式选择后查看“基于历史持仓的情景”；不能静默切换到旧日期。

场景接口目前没有独立的实际风险日期字段，仅看到请求日期不能证明风险来源同日。研发需要沿现有风险张量读面核实实际来源日期、组合范围和回退状态，必要时作最小契约补充。核验不通过时暂不显示金额，保留缺口原因和风险详情入口。

无权限时只显示权限受限状态，不请求额外持仓明细，不影响公开于该用户的市场信息。金额为零与来源缺失必须区别：已核验零敏感性显示0，`source_missing` 显示不可用。

显示组合总影响前，还须证明适用口径内的持仓风险覆盖完整。按正式口径正常排除的资产，与应计入却缺少风险输入的资产分别披露。覆盖不全时，只有后端能明确返回已覆盖范围、缺失或排除项及对应部分情景，才可显示“已覆盖持仓情景”；否则不显示影响金额。不能将部分汇总称为完整组合结果，也不能将接口返回非空金额视为覆盖完整的证明。

一期只提供组合层面的敏感性，不提供账户损益或其他综合收益拆分。要回答“哪个账户影响最大”，后续必须取得相同风险口径下的账户分项和一致日期，不能按市值占比分摊组合影响。

## 八、判断、日期与异常状态的统一规则

判断以依赖项为边界。政策基准缺失仅阻断政策偏离及依赖它的判断；有效 DR007 原值和自身跨期变化可以保留。风险数据缺失只阻断情景金额，不阻断已经核验的曲线事实。

全页综合判断被阻断时，不得残留没有使用限制的当日方向标签。若现有回执只能证明全局失败、无法识别哪些依赖仍有效，则保守停止当前方向判断，保留带日期与警告的原始观测。只有后端能证明某条局部判断的全部依赖及相应回执有效，才可单独恢复该判断，并说明其适用范围。

| 状态 | 用户看到的结果 |
| --- | --- |
| 证据齐全且已核验 | 显示对应观察期的事实判断与依据 |
| 部分节点缺失 | 显示有效局部事实，说明整体判断受限 |
| 来源待核验 | 保留原始观测和日期，停止相关推断 |
| 刷新或读取失败 | 显示失败原因；保留旧值时标明旧日期 |
| 数据回退 | 显示实际回退日期及使用限制 |
| 风险日期不匹配 | 停止同日情景金额，提供显式历史日期选择 |
| 无权限 | 显示受限入口，其他独立区域正常使用 |

页面区分资金观察日、曲线观察日、比较日、政策生效日、月度统计期和风险数据日。资金与曲线观察日不同，或各自比较区间不同，均不生成两者同步变化的联合判断；独立有效事实仍按本块日期展示。不能使用“页面生成时间”代替数据日期，也不能将几类日期压成一个全页截止日。对日行情的陈旧判断复用既有日期规则；交易日连续性在日历来源未核实前不得自行推算。

行情变化的颜色只代表上行、下行或无变化，附近保留文字和正负号；它不自动表达对组合有利或不利。图表和表格使用统一格式，收益率保留足够精度，变化以 bp 显示。非零微小变化不得被格式化成0；可显示更高精度或带方向的“小于0.01 bp”，原值在依据中完整保留。

## 九、接口复用与最小实现边界

一期沿用快照作为市场首屏的主要读取入口。资金、曲线的业务派生量和判断在后端形成，前端只负责显示、格式化和交互。情景结果在用户打开后单独读取，不因首页增加两个分析区就同步启动全部宏观、联动和策略分析。

| 现有入口 | 一期用途 | 实现要求 |
| --- | --- | --- |
| `/ui/market-overview/snapshot` | 首屏状态、事实与两块分析摘要 | 按需补充页面专用判断和依赖信息 |
| `/ui/market-data/rates` | 正式利率证据 | 保留序列口径及来源限制 |
| `/ui/macro/choice-series/latest` | 原始观测与补充证据 | 不把全部序列直接纳入方向判断 |
| `/api/risk/scenario-stress` | 固定利率冲击结果 | 按具体情景键读取，验证来源日期 |
| `/api/macro-bond-linkage/analysis` | 现有专题分析 | 一期不新增首屏依赖 |

每条新增判断至少要能返回：判断文本、观察和比较日期、有效状态、必要证据引用、失效原因、规则版本及核验入口。每项派生数值还须返回单位、输入序列及其日期、是否代理、是否回退。上述是目标业务契约，不表示当前 DTO 已具备这些字段；具体命名在接口设计中与现有契约统一，不新增通用分析框架。

曲线跨期比较所需的公共基期、政策有效区间和风险实际日期若现有返回不足，应在正确的已有后端链路补充。前端不能用最近可见值自行拼接。请求切换或返回乱序时，摘要、图表和证据必须仍属于同一数据版本和对应观察期，旧请求不得覆盖新状态。

现行页面契约将本页定位为模块入口；本需求会增加两块分析观察及情景摘要。实施时应同步更新 [页面契约](page_contracts.md)，维持分析展示与正式指标边界。本轮仅新增需求文档，不提前将目标行为写为现状。

## 十、可直接使用的验收样例

以下数字全部为合成验收样例，不是实际行情、持仓或收益预测。市场日、比较日和政策生效记录由测试夹具明确提供，禁止用运行当天日期代替。

**政策偏离正常。** 当有效政策利率为1.40%、同日DR007为1.50%时，展示高于基准10 bp，并能打开两项输入及生效证据；页面不能因此自动写“货币政策收紧”。

**政策生效证据缺失。** 即使最近一次操作利率为1.40%，若无法证明它在DR007观察日有效，偏离应不可用。DR007自身原值仍可显示，图表不得暗中延续操作利率。

**代理名称准确。** 输入序列为 `NCD.SHIBOR.3M`、数值为1.43%时，所有业务区域、提示和依据均显示SHIBOR 3M，不出现真实存单收益率的含义。

**收益率与期限利差闭合。** 同一基期2年、10年国债分别为1.30%、1.70%，当期分别为1.25%、1.68%时，展示变化为−5 bp、−2 bp；10年减2年利差由40 bp变为43 bp，扩大3 bp。图表、摘要和明细一致。

**覆盖不足。** 上述样例缺少5年数据时，仍可解释2年与10年的变化及其利差，但不得给出覆盖2、5、10年全曲线的判断。缺少2年节点时，10年减2年利差不可用。

**日期不能拼接。** 同一期2年和10年节点来自不同交易日时，不计算二者利差；跨期比较中任何必要节点的起止日期不同，不输出整体曲线形态。

**两块观察日期不同。** 资金观察日为9月7日、曲线观察日为9月4日时，两块分别标明日期，不称“今日资金与债市同步变化”；固定利率情景默认检查9月4日风险结果，不使用9月7日替代。

**刷新失败。** 总体回执为blocked且无法证明局部依赖有效时，当前方向判断关闭；页面可以保留带警告的原始观测，不残留无限制的“偏松、震荡、中性”。

**局部失败不扩散。** 政策基准缺失而国债两期数据已核验时，资金偏离不可用，曲线事实正常。风险情景接口失败时，两块市场分析保持有效状态。

**全局失败但局部可证明有效。** 总体回执blocked，后端能证明曲线必要输入及对应回执全部有效，而资金依赖失败时，保留带观察日的曲线事实判断，关闭资金判断。全局提示明确受限范围，不能宣称所有判断都已关闭。

**固定情景口径准确。** 合成监管DV01为1,000元/bp且后端返回上行10 bp影响−10,000元时，页面正确显示该结果、监管口径、风险日和需复核标识。前端不重算，也不生成下行10 bp结果。

**风险日期和缺失状态准确。** 曲线观察日为9月4日而风险实际日期为8月31日时，不自动显示“同日组合影响”；用户显式选择历史日期后才可显示历史持仓情景。实际日期无法证明、来源缺失或权限不足时不显示金额。

**部分持仓有风险缺口。** 接口返回了金额，但适用范围内仍有持仓缺少监管DV01时，不显示完整组合总影响。能够明确核验部分范围与后端部分结果时，显示“已覆盖持仓情景”及缺口；无法核验时不显示金额。

**颜色与精度准确。** 0、null和正负微小变化显示不同；0.0006个百分点应对应0.06 bp，不能写成0.0006 bp或0。红绿颜色不替代文字，也不自动变成收益利好、利空。

**证据与交互可用。** 从任一结论至其数据依据不超过两次操作；键盘能打开和关闭依据、返回原焦点。1440、1024和390像素宽度下主结论、单位和状态可读，页面无整体横向溢出，必要的明细表可局部滚动。

**读取与刷新一致。** 首屏不等待完整联动和情景计算；情景按需加载。刷新失败不提示成功，不把旧结论配到新图表；纯查看、展开和跳转不得触发数据写入或刷新任务。
