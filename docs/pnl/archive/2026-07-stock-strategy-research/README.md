# 2026-07 Stock Strategy Research Archive

This archive keeps one-off stock-strategy research outputs out of the active `docs/pnl/` root while preserving the evidence.

## Layout

- Root files: original batch2/batch3 reports and baseline research outputs.
- `final-rerun/`: later batch3 final/v2 rerun reports generated by `scripts/run_batch3_stock_strategy_research.py`.
