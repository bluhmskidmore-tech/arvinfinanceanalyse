## 修复结果

固收计算存在临近付息日漏算票息的实质问题。原来的宽日历容差会把估值日之后仍未支付的一期现金流归并掉。以 2026-03-30 估值、2056-03-31 到期、年付息且票息和收益率均为 3% 的合成债券为例，未来应有 31 笔现金流；修复前久期约为 20.18845459 年，按真实付款日独立计算应为 19.61481619 年。现有日期路径保留真实未来票息，久期、凸性和 KRD 相关调用传入估值日及到期日。债券规则升级为 v4，风险张量规则升级为 v9，避免与已有 v3/v8 数据混用。原有整付息日采用 k/f、非整付息日采用实际日期的兼容口径仍保留，未把这次修复宣称为全系统日计数统一。

Campisi 的部分期限覆盖原来只披露缺失，却仍把已知期限均值用于全组合的曲线形态、信用和凸性分解。现在这些分量受覆盖状态约束，未解释金额留在残差，平行利率分量及损益闭合保持可核对。完全缺失期限时原有明确披露的三年兼容回退未在本轮扩大修改。新增反例在修复前失败，相关 73 项回归在修复后通过，并获独立会计角色复验。

TPL 相关性计算原来把 NaN 转成零，形成虚假的相关系数和损益合计。现仅使用有限观测对，受污染合计以 `Numeric.raw=null` 表达并保留质量告警。信用利差的无效收益率也改为缺失，合法零收益率和负收益率继续有效，避免生成无依据的负利差。后端同时修复了 DuckDB `rowcount=-1` 导致的市值回填漏插入，将 Cube 存储异常处理移回服务层，并修复影子脚本直接启动时的导入路径问题。

前端修复了债券模拟数据分组截断后分母未同步的问题，并更新与现行页面合同不一致的测试。产品损益页详情文字改用已有主题文字色，股票页的最小点击目标检查改为覆盖现行研究台的真实价格图区间按钮，修复后完整可访问性、股票几何与导航组 63 项通过。人工截图另发现首页顶栏文字重叠，根因是较高优先级样式覆盖了可换行布局，且首行固定为 42px。修复后 1280px 窗口实测顶栏高 88px、左右控件分两行、主内容从 y=88 开始，视觉合同 11 项通过。牵头代理再次独立运行首页浏览器检查并查看新截图，确认文字不再重叠。

市场总览的增量审查发现 NaN/Infinity 会被标成正常数值并导致 JSON 响应序列化失败。服务入口及行情、宏观、图表等实际受影响分支改为有限数校验，无效数降为缺失并披露降级状态，合法零值和负值保留。验收使用真实响应模型和 JSONResponse 的序列化反例，覆盖仅检查模型类型时漏掉的 500 错误。后续并发增加的缺失行情与零命中短缓存逻辑也单独复核：新生成的不可用结果缓存 15 秒，命中不延长过期时间，超时保留可重试 503。补齐旧缓存适配器的兼容、同步市场总览 rule/cache v6 后，牵头代理以仓库根 `.venv` 和隔离环境复跑最新九文件，128 项全部通过。此前并发测试先改成 v6、服务仍为 v5 造成的六项失败也保留了原始记录，没有回退测试期望来制造通过。

文档与工具审查纠正了把归档脚本视作生产生效、把旧研究视作当前版本复验等不实表述。回测报告生成器现在使用输入载荷中的引擎版本及本次去重计数，不再硬编码前次基数或声称未经比较的业绩不变；五条反例先失败后通过，连同既有回归共 35 项通过，历史 JSON 和业绩表格保持原值。v2 研究结果不能作为 v3 复验结论。

最后并发补入的 `TTLResponseCache.shorten_if_same` 也由牵头代理增量审查。该方法在锁内确认缓存仍持有同一对象，只缩短过期时间，不覆盖替换值或复活过期项。市场总览相应改用这一接口；旧 API 测试夹具补齐方法后，原有业务断言继续执行。包含真实缓存过期、替换保护、并发代次及市场总览的最新十文件最终通过 150 项，原始失败日志一并保留。

## 保留边界

既有 role-less 显式授权和 provider 研究上下文权限属于保留的政策观察，本轮没有扩大认证与权限框架。平均余额历史授权表述没有被当成新增业务审批凭据。当前代码验收、历史记录、业务 owner 审批和生产部署分别记录；本轮不执行正式数据重算，不重启或切换用户正在使用的 5888/7888 服务，不推送远端。

周期轮动的官方发布日配置通过了本地语法、绑定和日期策略测试，但没有在本轮重新取得外部官方发布材料。这项代码合同验收不能替代来源事实的业务核验。

本地敏感模式扫描未发现实际密钥，命中的两处均为配置示例或测试占位符。机器未提供 Gitleaks 可执行程序，因此该项证据仅表示已执行的本地模式检查，不宣称完成完整密钥审计。
